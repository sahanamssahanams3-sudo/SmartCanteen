## Admin pages
- admin/dashboard.php — cards, recent orders, alerts, quick actions
- admin/orders.php — all orders + status updates
- admin/products.php — add/edit/delete/toggle products + image upload
- admin/inventory.php — add/edit/delete inventory + low-stock tracking
- admin/users.php — customer/staff/admin role and status management
- admin/offers.php — add/edit/delete/toggle offers and discounts
- admin/reports.php — sales, completed/cancelled orders, best-selling products

All admin pages require the admin role. Customer and staff pages are separate. Products are saved to data/menu.json through the Admin UI.
